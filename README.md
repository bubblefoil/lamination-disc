# Lamination disc

Parametric lamination disc generator: coil slots on the bore, optional alignment tab pairs on the rim, and per-plate stack skew. Exports a single plate or the whole stack as SVG or DXF (R12) for laser cutting — black / layer `CUT` is cut, red / layer `ENGRAVE` is engrave.

Live: https://bubblefoil.github.io/lamination-disc/

Everything runs in the browser from a single `index.html`; no build step.
